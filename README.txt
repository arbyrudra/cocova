WHAT'S IN THIS FOLDER
---------------------
index.html          The complete website (HTML + CSS + JavaScript in one file).
assets/             All images used by the site.
README.txt          This file.


HOW TO VIEW IT
--------------
Double-click index.html and it opens in any web browser.
Keep index.html and the assets folder together in the same place —
if you move index.html on its own, the pictures will not show.

(If you only want a single file you can email or share, use
cocova-website.html instead — every image is built into that one file.)


HOW TO PUT IT ONLINE
--------------------
Upload the CONTENTS of this folder (index.html + the assets folder)
to your web host's public folder — usually named public_html, www, or htdocs.

Works with any normal web hosting, plus free options such as
Netlify, Vercel, Cloudflare Pages or GitHub Pages.
No database, no PHP, no build step, no installation required.


WHAT'S ON THE PAGE
------------------
1. Hero          — brand introduction

3. Your Perfect Shake — the menu, in four tabs:
                   Everyday Classic (10), Signature (10),
                   Indian Special (6), Coffee (4)
                   Each row scrolls sideways: drag, swipe,
                   mouse wheel, or the arrow buttons.
4. Fresh Coco Treats — brownies, waffles, donuts
5. Our Space     — photos of the cafe
6. Visit Us      — address, hours, phone, map link
7. Footer        — contact details and links


MAKING CHANGES LATER
--------------------
Everything lives in index.html. Open it in any text editor.

To change a price, search for the item name (for example "Kitkat Loaded")
and edit the number next to it.

To change a photo, replace the matching file inside the assets folder,
keeping exactly the same filename.

To change the phone number or address, search for "96388" or "Sardar Patel".


A NOTE ON THE IMAGES
--------------------
The cafe interior photos (interior-1.jpg, interior-2.jpg, shop-counter.jpg)
are genuine photographs of COCOVA.

The drink and dessert pictures are studio-style product images created for
this site. Swap in real photos of your own shakes whenever you have them —
just replace the files in assets/ using the same filenames and the site
will pick them up automatically.
